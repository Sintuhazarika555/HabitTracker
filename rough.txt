4, src/config/db.js , setup of database
5, src/models/habit.model.js ,schema acts as a contract for what fields are allowed, their data types, and validation rules

In MongoDB, Mongoose needs model files (habit.model.js) to define schemas and validate fields before saving documents.
In MySQL, your database tables (habits and habit_logs) are the schema. MySQL handles data types, default values, and foreign keys directly on the database engine.

6, src/controllers/habit.controller.js, Controllers extract data from the incoming request (req.body, req.params), interact with the database model, and send an HTTP response (res).
